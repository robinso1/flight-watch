# flight-watch

Бесплатный мониторинг цен на билеты EVN - LED и LED - EVN на 15-18 декабря 2026. Опрашивает Google Flights раз в 30 минут через GitHub Actions, пишет историю в data/prices.csv и шлет алерты в Telegram.

Запуск, 10 минут.

Шаг 1. В Telegram откройте @BotFather, команда /newbot, задайте имя, получите токен. Затем напишите своему новому боту любое сообщение и откройте в браузере https://api.telegram.org/bot<ТОКЕН>/getUpdates - в ответе найдите "chat":{"id":число}. Это ваш chat id.

Шаг 2. На github.com создайте публичный репозиторий (Public, иначе минуты Actions платные), загрузите в него все файлы из этой папки. Папка .github может не подхватиться при перетаскивании: тогда создайте файл через Add file - Create new file с именем .github/workflows/watch.yml и вставьте содержимое.

Шаг 3. Settings - Secrets and variables - Actions - New repository secret. Добавьте два секрета: TG_TOKEN и TG_CHAT. Токен и chat id в файлы и в чаты не вставляйте, репозиторий публичный.

Шаг 4. Вкладка Actions - flight-watch - Run workflow. Через минуту в Telegram придет стартовое сообщение со всеми ценами и списком перевозчиков, которых Google реально показывает. Если там нет FlyOne или «России», значит, Google их не отдает, и нужен другой источник. Напишите, добавим.

Настройки в config.json: dates - даты, max_stops - 0 только прямые (null - любые), threshold_rub - ваш порог цены в одну сторону, combo.threshold_rub - порог на пару туда-обратно, min_stay_days - минимум дней между вылетами туда и обратно. Новое направление добавляется блоком в routes.

Ограничения. GitHub запускает cron с задержкой, реальный интервал 30-45 минут. Google может отдавать капчу адресам GitHub: если проверки падают три раза подряд, бот напишет об этом сам. Расписание отключается после 60 дней без активности в репозитории, поэтому скрипт раз в неделю обновляет файл data/keepalive.txt.
